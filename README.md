# 🛡️ Cyber Security Downloader

**Cyber Security Downloader** — портативный загрузчик для Windows, который объединяет несколько популярных инструментов безопасности в одном удобном интерфейсе.

Программа позволяет быстро получить актуальные версии **Dr.Web CureIt!**, **AdwCleaner** и других поддерживаемых утилит, проверить состояние локального файла, загрузить обновление и сразу запустить скачанную программу.

Проект написан на **Python + CustomTkinter**, имеет открытый исходный код и не требует установки.

## ✨ Основные возможности

* 🦠 **Несколько инструментов безопасности** в одном приложении
* 🔄 **Проверка обновлений** перед загрузкой
* 📊 **Сравнение размера локального и удалённого файла**
* ⚡ **Отображение скорости и прогресса загрузки**
* ⏱️ **Расчёт примерного оставшегося времени**
* 🔐 **HTTPS-загрузка** с проверкой полученного файла
* 🛡️ Проверка загруженного `.exe` на корректный Windows PE-заголовок
* #️⃣ Вычисление **SHA-256** после загрузки
* ❌ Возможность **отменить загрузку**
* ▶️ **Запуск скачанной утилиты** прямо из программы
* 📁 Выбор папки для сохранения файлов
* 📦 Портативный режим без установки
* 🔊 Звуковое уведомление после успешной загрузки
* 🌍 Интерфейс на нескольких языках
* 🌙 Современный тёмный интерфейс на CustomTkinter
* 💾 Сохранение настроек между запусками

## 🧰 Поддерживаемые инструменты

### Dr.Web CureIt!

Автономный антивирусный сканер для проверки компьютера на наличие вредоносных программ.

### AdwCleaner

## 🔐 Безопасная загрузка

Cyber Security Downloader не является антивирусом. Его задача — предоставить удобный способ получения сторонних инструментов безопасности.

При загрузке программа:

1. Подключается к серверу через HTTPS.
2. Получает информацию о размере файла.
3. Загружает файл во временное `.tmp`-хранилище.
4. Показывает прогресс и скорость загрузки.
5. Проверяет размер полученного файла.
6. Для `.exe` проверяет наличие корректного Windows-заголовка `MZ`.
7. Вычисляет SHA-256.
8. Только после успешной проверки перемещает файл в конечное расположение.

Это позволяет избежать ситуации, когда вместо исполняемого файла сохраняется HTML-страница ошибки или повреждённый результат загрузки.

## 📦 Портативность

Программа не требует установки.

Можно использовать:

* готовую `.exe`-сборку;
* исходный Python-код;
* папку `Downloads` рядом с программой;
* любую выбранную пользователем папку.

Настройки сохраняются в `settings.json`.

## ⚠️ Важно

Cyber Security Downloader **не является антивирусом** и не заменяет специализированные средства защиты.

Загрузчик предназначен для удобного получения и запуска поддерживаемых инструментов.

Готовая portable `.exe`-сборка также может отображать предупреждение Windows SmartScreen, если файл не имеет цифровой подписи издателя.
