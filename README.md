# Cyber Security Downloader Pro 🛡️

Портативная утилита с открытым исходным кодом для автоматической загрузки, проверки обновлений и запуска антивирусных сканеров (**Dr.Web CureIt!** и **AdwCleaner**).

![License](https://img.shields.io/badge/License-MIT-green.svg)

---

## 🌟 Основные возможности

* **Автоматическая проверка обновлений:** при запуске определяет актуальность вирусных баз на официальных серверах.
* **Звуковые уведомления:** приятный аудиосигнал по окончании загрузки.
* **Защита от ошибок скачивания:** проверка структуры `.exe` файлов (защита от загрузки битых файлов, обрывов связи и веб-страниц с ошибками).
* **Портативный режим:** поддержка работы с папкой `Downloads` рядом с программой или выбор произвольной директории.
* **Быстрый запуск:** открытие скачанной утилиты и целевой папки прямо из интерфейса.
* **Сохранение конфигурации:** автоматическое запоминание последней выбранной утилиты и путей в `settings.json`.

---

## ⚠️ Предупреждение о безопасности (False Positives)

Исполняемый файл `.exe` собран из Python-кода с помощью PyInstaller и **не содержит платной цифровой подписи**. Из-за этого Windows SmartScreen или антивирусы могут выдавать предупреждение при запуске. Это стандартное ложное срабатывание. 

Код полностью открыт для аудита, также вы можете запустить приложение напрямую из исходников.
