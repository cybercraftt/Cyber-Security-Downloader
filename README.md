# 🛡️ Cyber Security Downloader Pro

**Cyber Security Downloader Pro** — портативная утилита с открытым исходным кодом для быстрого скачивания и запуска популярных средств безопасности для Windows.

Программа объединяет **Dr.Web CureIt!** и **AdwCleaner** в одном простом интерфейсе и позволяет загружать актуальные версии непосредственно с официальных серверов разработчиков.

## ✨ Возможности

### 🦠 Две утилиты в одном приложении

Поддерживаются:

* **Dr.Web CureIt!** — автономный антивирусный сканер.
* **AdwCleaner** — инструмент для удаления Adware, PUP и нежелательных компонентов браузеров.

Переключение между утилитами осуществляется непосредственно из интерфейса программы.

### ⚡ Быстрая загрузка

Программа загружает файлы непосредственно с серверов соответствующих разработчиков.

Во время загрузки отображаются:

* текущий объём загруженных данных;
* общий размер файла;
* скорость загрузки;
* индикатор прогресса.

### 📦 Портативность

Программа не требует установки.

Можно использовать:

* `.exe`-версию;
* исходный Python-код;
* папку рядом с программой;
* пользовательскую директорию для сохранения файлов.

### ▶️ Быстрый запуск

После завершения загрузки скачанную утилиту можно запустить непосредственно из Cyber Security Downloader Pro.

Если файл уже находится в выбранной папке, программа автоматически обнаружит его и предложит запустить или обновить.

### 🔊 Уведомление о завершении

После успешного завершения загрузки программа воспроизводит короткий звуковой сигнал.

Файл `alert.wav` можно разместить рядом с программой.

### 🎨 Современный интерфейс

Интерфейс построен на **CustomTkinter** и выполнен в тёмном стиле.

Основной упор сделан на:

* минималистичный дизайн;
* понятный статус загрузки;
* крупный индикатор прогресса;
* минимум лишних элементов.

## 🔐 Безопасность

Cyber Security Downloader Pro не является антивирусом и **не заменяет Dr.Web CureIt! или AdwCleaner**.

Программа предназначена только для получения и запуска этих инструментов.

Исходный код открыт, поэтому работу загрузчика можно самостоятельно проверить перед использованием.

> **Важно:** перед запуском загруженных `.exe` рекомендуется самостоятельно убедиться, что файл получен с официального источника и не был изменён.

## ⚠️ Windows SmartScreen и антивирусы

Готовая `.exe`-версия может отображать предупреждение Windows SmartScreen или другого защитного ПО.

Это может происходить потому, что portable-сборка Python-приложения создана с помощью **PyInstaller** и не имеет платной цифровой подписи издателя.

При возникновении предупреждения рекомендуется:

1. Проверить исходный код проекта.
2. Скачать программу из официального репозитория.
3. При необходимости собрать `.exe` самостоятельно.
4. Проверить полученный файл средствами безопасности Windows или другим доверенным антивирусом.

## 🚀 Запуск из исходного кода

### 1. Клонирование репозитория

```bash
git clone https://github.com/cybercraftt/Cyber-Security-Downloader.git
cd Cyber-Security-Downloader
```

### 2. Установка зависимостей

```bash
pip install customtkinter
```

Если используется поддержка изображений:

```bash
pip install pillow
```

### 3. Запуск

```bash
python main.py
```

> Название основного Python-файла измените на фактическое имя файла в репозитории, если оно отличается от `main.py`.

## 🛠️ Технологии

Проект написан на Python и использует:

* **Python 3**
* **CustomTkinter** — графический интерфейс
* **urllib** — загрузка файлов
* **threading** — выполнение загрузки в отдельном потоке
* **Pillow** — работа с изображениями
* **PyInstaller** — создание portable `.exe`
